## 📌 О проекте

Здесь собраны материалы по информационной безопасности (ИБ). Принципы такие:

- **Простой язык.** Объясняем так, чтобы понял человек без технического образования.
- **Минимум воды.** Только суть: что это, как работает, реальный пример, как защититься.
- **Каждый термин объяснён.** Новый термин сразу расшифровывается, а полное определение есть в [📖 Глоссарии](glossary.md).
- **Каждое утверждение проверяемо.** У каждого раздела есть ссылки на первоисточники. Сводный список лежит в [📚 Источниках](SOURCES.md).

## 🧭 Как читать

1. **Новичкам:** начните с [базовых понятий](threats/00-basics.md), потом читайте разделы по порядку.
2. **Ищете конкретную тему:** выберите её в таблице выше. Каждый раздел можно читать отдельно.
3. **Встретили непонятное слово:** нажмите на него. Термины ведут в [глоссарий](glossary.md).

Условные обозначения:

| Значок | Значение |
|:-:|---|
| 💡 | Что это простыми словами |
| ⚙️ | Как это работает |
| 📰 | Реальный случай |
| 🛡️ | Как защититься |
| 🏷️ | Классификация в MITRE ATT&CK и других каталогах |

> [!IMPORTANT]
> Материалы предназначены для обучения и защиты. Здесь объясняется, *как устроены* угрозы, чтобы от них защищаться, а не инструкции по атакам.
